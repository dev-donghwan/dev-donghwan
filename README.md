## About Me
- 저는 현재 Posicube라는 회사에서 Java 기반 Spring Boot 백엔드로 약 3년간 재직중인 개발자입니다.
- 주요 관심사는 의존성이 낮으며 확장 가능한 코드를 설계하고 구현하는 것입니다. 이를 위해 객체지향 프로그래밍과 설계원칙에 대해 공부하고 적용하고 있습니다.
- 최근 Mocking을 통한 UnitTest를 통해 기능 검증과 비동기 처리 과정에서 메모리를 효율적으로 처리할 수 있는 방법에 대해 많은 경험과 발전을 이루었습니다.
- 중기목표는 JVM 언어가 아닌 Node.js 또는 Python 기반 언어로 서버를 개발해보려는 목표를 가지고 있습니다.
- 장기목표는 확장성이 높은 프로그램을 구현하면서 데이터와 테스트에 기반한 안전한 프로그램을 설계하고 구현하는 개발자가 되고자 합니다.
